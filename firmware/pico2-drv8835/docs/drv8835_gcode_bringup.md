# Pico 2とDRV8835による標準G-code運転手順

## 対象

この手順はRaspberry Pi Pico 2 WH/Pico 2 W、秋月電子AE-DRV8835-S 4個、XY平面モータ基板を
`pico2_gcode_drv8835_xy.uf2`または`pico2w_gcode_drv8835_wifi.uf2`で動かす場合を対象にします。
診断用の`M974`から`M978`は通常運転では使用しません。

## 配線

各相には実機で動作を確認した1.5Ω、5W以上の直列抵抗を入れます。Pico、4個の
DRV8835、外部電源のGNDは共通にします。DRV8835のMODEはGNDへ接続します。

| 軸 | 平面基板 | DRV8835出力 |
|---|---|---|
| X | A+ / A- | AOUT1 / AOUT2 |
| X | B+ / B- | BOUT1 / BOUT2 |
| Y | C+ / C- | AOUT1 / AOUT2 |
| Y | D+ / D- | BOUT1 / BOUT2 |

| 軸 | DRV8835制御入力 | Pico GPIO | Pico物理ピン |
|---|---|---:|---:|
| X | AIN1 | GP19 | 25 |
| X | AIN2 | GP20 | 26 |
| X | BIN1 | GP21 | 27 |
| X | BIN2 | GP22 | 29 |
| Y | AIN1 | GP15 | 20 |
| Y | AIN2 | GP16 | 21 |
| Y | BIN1 | GP17 | 22 |
| Y | BIN2 | GP18 | 24 |

相順はXが`A+ → B- → A- → B+`、Yが`C+ → D- → C- → D+`です。
GP2～GP5は将来のmicroSD用として未使用です。GP12はPWMサーボZに使用します。
GP12はDRV8835出力と異なるPWMスライスなので、50 Hzのサーボ信号を設定してもXYの20 kHz PWMへ影響しません。
GP8～GP11は任意のAS5600二系統I2C、未使用のGP13とGP14は起動時にLowへ固定します。

### 4モジュール制御基板との互換性

`drv8835-control-board/`では1相にAE-DRV8835-Sを1個使い、モジュール内の2個のHブリッジを
並列化しています。各相の`AIN1=BIN1`、`AIN2=BIN2`へ同じGPIO信号を入れ、
`AOUT1=BOUT1`を相の`+`、`AOUT2=BOUT2`を相の`-`へ接続します。これは旧ブレッドボード試験の
論理信号と同じで、専用ファームやピン変更は不要です。MODEはGNDのIN/INモードです。

| 相 | IN1 / IN2 | 出力 | U1正方向の励磁順 |
|---|---|---|---|
| A | GP19 / GP20 | A+ / A- | 1番目、A+ |
| B | GP21 / GP22 | B+ / B- | 2番目、B- |
| C | GP15 / GP16 | C+ / C- | 1番目、C+ |
| D | GP17 / GP18 | D+ / D- | 2番目、D- |

名刺4枚サイズフレキも各相5 mmピッチ、B/D相2.5 mmオフセット、端子順を維持しているため、
`DEFAULT_STEPS_PER_MM=0.4`と相順は変更しません。ただし各相の概算抵抗は約1.25～1.36Ωです。
さらに1.5Ω直列抵抗を入れてVM=3.0 Vとした場合、配線・ドライバ損失を無視しても電流上限は
約1.05～1.09 Aです。旧試作より磁力が不足し、見かけ上の脱調になる可能性があります。

### PWMサーボZ配線

| 信号 | Pico GPIO | Pico物理ピン | 接続 |
|---|---:|---:|---|
| サーボPWM | GP12 | 16 | PWMサーボの信号線 |
| サーボ電源 | - | - | 外部安定化5 V |
| サーボGND | GND | 任意GND | Pico、DRV8835、外部5 Vと共通 |

GP10はDRV8835版では第2 AS5600のI2C1 SDAとして使用します。DYNAMIXEL用ファームとは
同時使用しないため、PWMサーボや現在のDRV8835出力とは競合しません。
サーボをPicoの3V3から給電しないでください。

### AS5600二系統の任意配線

| 関節 | AS5600 SDA | AS5600 SCL | 電源 | 未接続端子 |
|---|---|---|---|---|
| J1 | GP8 / 物理11番 | GP9 / 物理12番 | 3.3 V / GND | OUT、PGO |
| J2 | GP10 / 物理14番 | GP11 / 物理15番 | 3.3 V / GND | OUT、PGO |

`DIR`は初回GNDへ接続します。2個とも同じ`0x36`ですが、J1はI2C0、J2はI2C1なので
アドレスマルチプレクサは不要です。片方または両方を接続しなくてもモータ運転は継続します。
将来のmicroSD用としてGP2～GP5は使用せずに残します。

## 電源と初期値

- DRV8835のVMは3Vから開始する
- 電源電流制限は1.5Aから開始する
- 各相の直列抵抗は1.5Ω、5W以上とする
- マイクロステップ相当分割数は1（単相励磁）
- X/YピークPWMは100%
- 最終移動から500ms後に出力を自動停止する

DRV8835には相電流をmAで設定する機能がないため、`M980`のX/Y値は電流値ではなく
PWM duty上限です。電流はVM、直列抵抗、基板配線抵抗、磁石位置で変化します。

## Z・ペン上下

`G0/G1`のZ値は連続位置補間ではなく、PWMサーボの上下状態へ変換します。既定では
`Z > 0.5`がペン上、それ以外がペン下です。XYを含まないZ命令は`M17`前でも実行できます。

```gcode
M281 U1000 D1800 T150 Z0.5
G0 Z1
G1 Z0
M3 S1400
M3 S1000
M5
```

| 命令 | 意味 |
|---|---|
| `M281 U... D... T... Z...` | 上パルス、下パルス、待機ms、上下判定値を設定 |
| `G0/G1 Z1` | ペン上 |
| `G0/G1 Z0` | ペン下 |
| `M3 S500..2500` | パルス幅usを直接指定。DYNAMIXEL版PlotterFlowとの互換用 |
| `M5` | ペン上 |

`M281`の設定範囲はU/Dが500～2500 us、Tが0～2000 msです。引数なしで現在値を表示します。
設定はFlashへ保存しません。`M18`、ジョグキャンセル、Ctrl-XではXY出力を停止し、ペンも上へ
戻します。一時停止`!`では描画再開を可能にするため、ペン状態を変えません。

## M980設定

```gcode
M980 U8 X60 Y60 I100 J100 H500 C100 B8 R16 A1
```

| 引数 | 範囲 | 意味 |
|---|---:|---|
| U | 1、2、4、8、16 | 2.5mmの1状態を分割する数 |
| X | 1～100 | X軸の通常走行PWM duty（%） |
| Y | 1～100 | Y軸の通常走行PWM duty（%） |
| I | 1～100 | X軸の初動PWM duty（%） |
| J | 1～100 | Y軸の初動PWM duty（%） |
| B | 0～10000 | 初動PWMを維持する軸ごとの実マイクロステップ数 |
| R | 0～10000 | 初動PWMから通常PWMへ線形に戻す軸ごとの実マイクロステップ数 |
| H | 0～5000 | 最終移動後に全出力をLowへ戻すまでの時間（ms） |
| C | 0～500 | 出力開始時に現在の電気角を初動PWMで捕捉する時間（ms） |
| A | 0 / 1 | `A1`は移動軸だけ励磁、`A0`は常にXY両軸を励磁 |

設定変更前には`M18`が必要です。引数なしの`M980`は現在値を表示します。設定はFlashへ
保存されません。`B0 R0`では初動ブーストが無効になり、従来どおりX/Yで指定した通常PWMを
常に使います。従来形式の`M980 U8 X100 Y100 H500 A1`もそのまま使用できます。
`A1`でもXY同時移動では両軸を励磁します。

## 初動ブースト

初動ブーストは、静止摩擦を越えるために移動開始時だけPWM振幅を変えるDRV8835内部機能です。
電気角、cos/sinマイクロステップ、`G0/G1`、`$J`の形式は変更しません。設定後は通常の移動命令へ
自動適用されるため、移動ごとに`M980`や専用移動命令を送る必要はありません。

ブーストは出力OFFまたはHi-Zから動き始める軸と、保持中に新しく励磁対象へ加わった軸だけで
開始します。X/YはBresenham補間で各軸が実際に進んだマイクロステップ数を別々に数えます。
捕捉中と最初の`B`ステップは初動PWMを使い、続く`R`ステップで通常PWMへ線形補間します。
移動完了後の保持出力は通常PWMです。移動が`B + R`より短い場合も軸ごとの進行度を保存し、
出力保持中に同じ軸の次のG1が始まれば、最初からやり直さず残りのブースト遷移を継続します。

出力を保持したまま同じ軸の短い`G1`が連続する場合、線分ごとには再ブーストせず、軸ごとの
実マイクロステップ数を線分間で引き継ぎます。
同じ軸の方向反転も、出力を保持している限り第1段階では再ブーストしません。`H`経過後、`M18`、
ジョグキャンセル、ソフトリセットなどで出力がLowになった後の次の移動では再び適用されます。
`M122`で通常PWM、初動PWM、設定ステップ数、`boost_active_mask`、軸ごとの`boost/run`状態を確認できます。

`I/J100`は常時100%ではなくても、開始時の電流、DRV8835、1.5Ω直列抵抗、電源配線の発熱を
増やします。低いVMと電流制限から短時間で確認してください。この機能はPWM振幅を開ループで
変えるだけで、加減速、初動時の電気角変更、電流測定、電流フィードバック、脱調検知は行いません。

## 最初の確認

VMを切った状態でUF2を書き込み、USBシリアルを115200設定で接続します。

```gcode
M115
M18
M281
M980
M122
```

`M115`に`pico2-gcode-drv8835-xy`、`M122`に`outputs=HiZ`が出ることを確認します。
GP15からGP22の使用ピンがLowであることを確認してから、VMを3V、電流制限1.5Aで投入します。
サーボ電源OFFでGP12が50 Hz、約1000 us High（ペンアップ）になっていることも確認します。

次を1行ずつ送り、X、Y、XYの順に確認します。

```gcode
M18
M980 U8 X60 Y60 I100 J100 H500 C100 B8 R16 A1
M281 U1000 D1800 T150 Z0.5
G0 Z1
M17
G21
G91
G1 X2.5 F300
G1 X-2.5 F300
G1 Y2.5 F300
G1 Y-2.5 F300
G1 X2.5 Y2.5 F300
G1 X-2.5 Y-2.5 F300
G1 Z0
G0 Z1
M122
M18
```

異常な発熱、電源のCC張り付き、配線抵抗の発熱があれば直ちにVMを切ります。`M18`、
ジョグ停止、Ctrl-Xでは全出力を即時Lowへ戻します。通常の線分間は励磁を継続し、最後の
移動から500ms後に自動停止します。

## PlotterFlow

コントローラープロファイルで`Pico 2 DRV8835 XY Planar（開発中）`を選択します。
プロファイルはジョブ開始時に`M18`、`M281`、`M980`、`G0 Z1`、`M17`、`G21`、`G90`、`G10 L20`を送り、
切断時に`M18`を送ります。ジョグは通常の`$J=G91 G21 X... Y... F...`です。
ペン上は`G0 Z1`、ペン下は`G1 Z0`です。DYNAMIXEL用プロファイルは従来どおり
`M3 S1400` / `M3 S1000`を使うため、アクチュエータごとの値を混同しません。

標準G-code試験は`examples/drv8835_xy_standard_gcode.gcode`にあります。円は`G2/G3`ではなく、
PlotterFlowと同じ`G1`線分列で近似します。

## PWM動作しきい値試験

PWM dutyを下げながら四角を周回する試験データを2種類用意しています。

- `examples/drv8835_pwm_threshold_square.gcode`: 各Dutyで10mm角を1周する推奨版
- `examples/drv8835_pwm_two_edges_square.gcode`: 2辺ごとにDutyを5%下げる比較版

推奨版はX正方向、Y正方向、X負方向、Y負方向を同じDutyで確認できるため、Duty差と軸・方向差を
分離しやすくなります。比較版は短時間で傾向を見られますが、各Dutyで2方向しか試さないため、
止まった付近は推奨版で再確認してください。

両方とも100%から40%まで5%刻み、`U1`の1相励磁、`A1`の移動軸のみ励磁、10mm角、
`F300`です。`B0 R0`で初動ブーストを無効にし、`I/J`を`X/Y`と同じ値にしているため、
捕捉時だけ高いDutyが加わることはありません。

`M980`はG-code実行途中でも使用できますが、設定変更前に`M18`が必要です。設定時は物理ステップと
電気角を現在の論理座標における基準相へ同期します。この試験は各Dutyの間で一度出力をLowにし、
500ms待ってから再設定・再捕捉するため、「動き続けられる最低Duty」ではなく
「停止状態から再び捕捉して動き出せる最低Duty」を測ります。静止摩擦を含む実用上の開始条件として
安全側の結果になります。

最初はVMと電流制限を安全な値にして100%の1周だけを手動送信し、正常に戻ることを確認してから
ファイル全体を送信してください。止まったDuty、軸、方向を記録し、その一段上のDutyを実用下限の
候補とします。連続運転値にはさらに5～10ポイントの余裕を持たせてください。
