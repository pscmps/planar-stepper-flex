# 配線表

## Pico 2 W GPIO

| 用途 | GPIO | 物理ピン | 備考 |
|---|---|---:|---|
| X A相 IN1 / IN2 | GP19 / GP20 | 25 / 26 | DRV8835 U2 |
| X B相 IN1 / IN2 | GP21 / GP22 | 27 / 29 | DRV8835 U3 |
| Y C相 IN1 / IN2 | GP15 / GP16 | 20 / 21 | DRV8835 U4 |
| Y D相 IN1 / IN2 | GP17 / GP18 | 22 / 24 | DRV8835 U5 |
| ZサーボPWM | GP12 | 16 | 50 Hz、既定はUp=1000 us、Down=1800 us |
| 電流センサ入力 | GP26 / ADC0 | 31 | 任意。未接続でも運転継続 |
| AS5600 J1 | GP8 SDA / GP9 SCL | 11 / 12 | I2C0、任意 |
| AS5600 J2 | GP10 SDA / GP11 SCL | 14 / 15 | I2C1、任意 |
| 将来microSD | GP2 SCK / GP3 MOSI / GP4 MISO / GP5 CS | 4 / 5 / 6 / 7 | 現ファームでは未使用 |

AS5600は3.3 Vで使用し、`DIR`は初回GND、`OUT`と`PGO`は未接続とします。センサがない場合もエラー停止しません。

## コイル出力

| 軸 | コネクタ順 |
|---|---|
| X | `A+ / A- / B+ / B-` |
| Y | `C+ / C- / D+ / D-` |

X/YのGNDは共通です。`VM_X`と`VM_Y`は通常分離し、同じ電源を使う場合だけ基板上のVMはんだジャンパを両方閉じます。ジャンパを閉じた状態で別々の電源を接続しないでください。

## AE-DRV8835-S

各相につき1モジュールを使い、A/Bの2ブリッジを並列にします。`MODE=GND`のIN/INモード、`VCC=3.3 V`、GND共通です。モジュールの詳細なピン順は秋月電子の説明書を参照してください。
