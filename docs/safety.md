# 安全上の注意

- DRV8835にはTMC2209のような相電流設定機能がありません。直列抵抗、電源電流制限、PWM dutyで電流を制限します。
- 初回はVMを低くし、各相へ1.5 ohm・5 W以上の直列抵抗を入れ、短時間だけ励磁します。
- FPC配線は低抵抗です。電源を直接つなぐと過電流、発熱、銅箔損傷の危険があります。
- 初動ブースト100%は連続運転用ではありません。抵抗、DRV8835、コネクタ、FPCの温度を確認します。
- VM-GND間へ電解コンデンサを配置し、極性と耐圧を確認します。
- 配線変更、導通測定、Pico書き込みはVMとサーボ電源を切って行います。
- `M18`、停止、キャンセル後に8出力がLowとなることをVM投入前に確認します。
- 製造した基板は最初に電流制限付き安定化電源で確認し、無人運転しないでください。
